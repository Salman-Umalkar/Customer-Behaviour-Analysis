# Customer Behaviour Analysis

## 📌 Project Overview
This project focuses on analyzing customer purchasing behavior in a retail/e-commerce environment using Python, SQL, and Power BI. The objective was to uncover business insights related to customer spending patterns, discounts, subscriptions, product performance, shipping preferences, and customer segmentation.

---

# 🎯 Business Problem
Retail businesses often struggle with:
- Low customer retention
- Ineffective marketing campaigns
- Poor understanding of customer preferences
- Identifying high-value customers
- Understanding seasonal demand trends

This project helps answer important business questions such as:
- Which categories generate the highest revenue?
- Do discounts increase purchase value?
- Which products are most popular?
- Are repeat buyers more likely to subscribe?
- Which age group contributes the most revenue?

# 🔍 Exploratory Data Analysis (EDA)

## Data Cleaning & Preprocessing
The following preprocessing steps were performed:

### ✅ Data Exploration
- Checked dataset structure
- Analyzed missing values
- Verified data types
- Generated statistical summaries

### ✅ Data Consistency Checks
- Corrected inconsistent product categories
- Standardized category mappings

### ✅ Missing Value Handling
- Filled missing sizes based on product category
- Used product-level average for review ratings
- Replaced missing purchase amounts with mean values
- Filled missing previous purchases with 0

### ✅ Duplicate Handling
- Removed duplicate customer records

### ✅ Column Standardization
- Converted column names to lowercase
- Replaced spaces with underscores

### ✅ SQL Integration
- Exported cleaned data into MySQL for advanced analysis

# 📈 Major Insights

## 💰 Highest Revenue Category
- Electronics generated the highest revenue.

## 🎟️ Discount Analysis
- Customers using discounts had higher average purchase values.

## 👥 Customer Segmentation
Customers were segmented into:
- New Customers
- Returning Customers
- Loyal Customers

## 🧓 Age Group Contribution
- Customers aged 51+ contributed the highest revenue.

## 📦 Shipping Insights
- Express shipping showed slightly higher average purchase values.

## ⭐ Product Insights
- Gloves and Sandals received the highest ratings.
- Phones and Headphones were among the lowest-rated products.
